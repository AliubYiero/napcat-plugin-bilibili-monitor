# 标题/分区变化事件仅在直播会话内触发

直播间变化检测按"直播会话"界定边界:每次开播(offline→streaming)重置状态基线,不继承上一场直播的标题/分区等字段;标题变化、分区变化事件仅在会话进行中(前后两次拉取状态均为 streaming)才触发,开播瞬间、结束直播瞬间与直播间隙的字段差异一律不产生变化事件。原因是旧实现按纯字段比对触发变化,一场直播结束后残留的标题/分区会与下一场新开播的字段产生"修改分区""修改标题"噪音推送(例:上一场分区 [网游-APEX],下一场开播直接是 [网游-无畏契约],却被推成"分区改变")。采用会话模型而非仅抑制开播瞬间,是考虑到直播间隙主播为下一场做准备而修改标题/分区的改动同样属于下一场的基线,不应单独推送;开播推送本身已携带新会话的完整状态。此改动改变了标题/分区推送的既有语义,故记录在案。
