# 未直播时同样检测标题/分区变化

直播间变化检测不再按"直播会话"界定边界（推翻原 ADR 0002）:标题/分区变化无论是否在播都会检测并触发事件,通过事件类型区分状态——直播中为 `title_changed`/`area_changed`,未直播为 `offline_title_changed`/`offline_area_changed`,后者作为独立推送类型在插件配置中可单独开关,默认启用。状态变化(开播/结束)仍会吞掉同一次比对到的标题/分区差异,避免开播推送与字段变化推送在同一轮轰炸。原 ADR 0002 抑制直播间隙字段变化的原因是防止跨场次残留噪音;改为区分事件类型后,用户可自行选择是否订阅未直播期间的变化,噪音问题由配置粒度解决。纯文本推送对 offline 类型附加"状态: 未开播"说明行,图片卡片则复用既有未开播样式。
