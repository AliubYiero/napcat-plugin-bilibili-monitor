# 直播变化推送采用外部 SVG 渲染插件生成卡片图片

直播状态变化通知（开始/结束直播、修改标题/分区）由纯文本推送升级为卡片图片推送：插件生成 SVG 代码，经外部渲染插件 `napcat-plugin-svg-render` 的 HTTP 接口渲染成 base64 图片，以 `[文本, 图片, 链接]` 三段式消息发送；渲染插件不可用或渲染失败时回退到原有纯文本逻辑（含标题/分区/时长）。选择外部渲染插件而非本地生成图片，是因为本地渲染需引入 canvas/字体等重依赖，且难以与渲染插件基于"微软雅黑"的字符宽度计算（卡片标题宽度动态伸缩，最小 700px、上限 1000px）保持一致。渲染依赖通过失败回退兜底，未引入配置开关。
