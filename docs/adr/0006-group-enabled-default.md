# ADR 0006: 群启用开关默认开启

日期: 2026-09-08
状态: 已采纳

## 背景

插件以群为单位提供启用开关 (`GroupConfig.enabled`)。未出现在
`groupConfigs` 中的群, 其启用状态必须有一个明确语义: 默认开启还是默认关闭。

## 决策

**默认开启**。判定式为宽松判定 `enabled !== false`
(`src/core/state.ts` 的 `isGroupEnabled`):

- 缺失字段、缺失整条群配置 → 视为启用;
- 仅显式 `enabled: false` 才禁用。

## 理由

- 零配置可用: 用户添加监控项后推送即时生效, 无需先去开关处启用一次。
- 监控类插件的打扰风险可控: 用户能收到推送恰恰是加了监控项的直接后果,
  不会出现"配置了却收不到通知"的困惑。
- 显式 `false` 的禁用操作路径清晰 (WebUI 群列表开关)。

## 后果

- 消息入口 (`message.handler`) 在最前端做 `isGroupEnabled` 短路。
- 该语义是插件的显式声明, 相关文档 (CONTEXT.md、config-pattern.md) 中
  不得含糊表述; 若未来改为默认关闭, 需修订本 ADR 并同步清洗/判定逻辑。
- 开关修改入口当前仅 WebUI, 群级指令开关为可能的后续增强 (另立任务)。
